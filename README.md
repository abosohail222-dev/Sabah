# كافيد (النسخة الشاملة)

برنامج لوحة تحكم تفاعلية لفروع الكافيه، مبني على نموذج التصميم المرفق.
صفحة HTML واحدة بدون سيرفر، تُنشر على GitHub Pages وتُثبَّت كتطبيق.

## الملفات
- `index.html` التطبيق كاملاً
- `manifest.webmanifest` و `sw.js` و `icon-192.png` و `icon-512.png` للتثبيت كتطبيق (اختيارية)

## النشر
Settings ثم Pages ثم Deploy from a branch (main و / root).

## ملاحظات
- البيانات تُحفظ في متصفح كل جهاز (localStorage) وملفات PDF في IndexedDB. لا تنتقل بين الأجهزة.
- لا يوجد تسجيل دخول. الأرقام الحالية تجريبية (زر "مسح البيانات" يفرّغها).
- يحتاج إنترنت أول مرة للخط ومكتبتي Excel وPDF.
- قراءة الفواتير تلقائياً (المصروفات والمشتريات) تعمل فقط عند فتح التطبيق داخل Claude، لأنها تستخدم Claude لقراءة الفاتورة. خارج Claude (مثل GitHub Pages) يبقى الإدخال يدوياً. لتفعيلها خارج Claude: أدخل مفتاح Claude API الخاص بك من «إعداد القراءة الآلية» في صفحتي المشتريات والمصروفات. يُحفظ المفتاح في متصفحك فقط ويُرسل مباشرة إلى Anthropic، ويُحاسَب الاستخدام على حسابك. لا تستخدمه على جهاز مشترك، وللاستخدام الجماعي يلزم سيرفر وسيط يحفظ المفتاح.

- قراءة الفواتير تدعم الملف الذي يحتوي على عدة فواتير: تُقرأ كل الصفحات (حتى 40 صفحة)، وتظهر كل فاتورة للمراجعة في المخزون أو تُنشأ لها سطر مستقل في المصروفات.


## تحديث (النسخة 3)
- الجرد: أعمدة الكمية والقيمة أول المدة، المشتريات وقيمتها، الكمية والقيمة آخر المدة، كمية وقيمة الاستهلاك، مع إجماليات أسفل الجدول.
- قائمة الدخل: إضافة بنود مصروفات أو إيرادات إضافية.
- التحليل: تقسيم المبيعات إلى البن والمطبخ مع تكلفة كل تصنيف ونسبتها، ومقارنة مع شهور سابقة بالمبلغ والنسبة. تقسيم مبيعات المطبخ يُدخل من صفحة جدول تفاصيل المبيعات.
